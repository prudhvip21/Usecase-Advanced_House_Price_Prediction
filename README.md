# House Price Prediction

Predict house sale prices and explain which property features drive them.

## Approach

- Exploratory analysis, outlier treatment and missing value handling
- Feature selection and statistical testing with statsmodels
- Linear regression with diagnostics

## Results

R-squared between about 0.78 and 0.85 across model versions in the saved notebook output.
